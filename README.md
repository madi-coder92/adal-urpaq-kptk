# ADAL URPAQ | Честный КПТК

Антикоррупционный сайт для студентов Карагандинского колледжа цифровых технологий и дизайна (КПТК).
Конкурс ADAL URPAQ, Карагандинская область. Направление 3: IT-решение (веб-сайт).

#SaryarqaJastary #AdalUrpaq #ЖастарЖастарға

## Описание

«Честный КПТК» помогает студенту пройти путь **Узнай → Проверь → Действуй**:

1. **Квиз «Адал Азамат»**: 9 реальных студенческих ситуаций, очки, серия верных ответов, 4 звания, лучший результат хранится на устройстве, результат можно скопировать и отправить другу.
2. **Генератор обращения**: форма превращается в готовый текст обращения (в администрацию колледжа, Антикор или управление образования). Текст можно скопировать или скачать. Сайт **ничего не отправляет и не сохраняет**.
3. **Блок «Твои права»**: пять коротких карточек: что можно требовать, что делать, куда идти. Телефон Антикора: 1424.
4. **Блок внедрения**: план запуска в колледже за 1 день и масштабирование.

Язык интерфейса: русский и казахский, переключатель в шапке.

## Целевая аудитория

Студенты КПТК 15–22 лет, в первую очередь первокурсники и те, кто впервые сталкивается с «неформальными договорённостями» вокруг зачётов, пересдач и допусков. Дополнительно: кураторы групп, заместитель директора по воспитательной работе. Сайт рассчитан на телефон: мобильная вёрстка, крупные кнопки, без регистрации.

## Архитектура

- Next.js 14 (App Router), React 18, Tailwind CSS, Framer Motion.
- **Без бэкенда и базы данных.** Весь контент лежит в `lib/i18n.js` (RU/KZ) и `lib/quiz.js`.
- Генератор обращения работает в браузере: `lib/report.js` собирает текст, скачивание через `Blob`, копирование через Clipboard API.
- В `localStorage` лежат только язык интерфейса и лучший результат квиза. Аналитики и cookie нет.
- Все данные колледжа вынесены в `lib/config.js`: чтобы запустить копию в другом колледже, достаточно поменять один файл.
- Шрифты: Unbounded (заголовки) и Manrope (текст), оба с кириллицей и казахскими буквами.
- Доступность: фокус с клавиатуры, `aria`-атрибуты, уважение к `prefers-reduced-motion`.

```
app/            layout и страница
components/     Header, Hero, Quiz, Report, Rights, Pilot, Footer, Providers
lib/            i18n.js, quiz.js, report.js, config.js, utils.js
docs/           концепция, презентация, письмо жюри
```

### Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # проверка сборки
```

### Деплой на Vercel

1. Залей папку в GitHub-репозиторий.
2. На vercel.com: Add New → Project → выбери репозиторий. Framework определится как Next.js.
3. Нажми Deploy. Переменные окружения не нужны.

## Социальная значимость

- Студенты чаще всего узнают о коррупционных рисках уже после того, как столкнулись с ними. Сайт даёт знание **до** ситуации и понятное действие **во время**.
- Снижает барьер обращения: человеку, который не знает, как писать официальное обращение, проще начать с готового шаблона.
- Не заменяет официальные каналы, а ведёт к ним: администрация колледжа, Антикор, управление образования.
- Приватность по умолчанию: нет базы, нет утечек, нечего собирать.
- Двуязычность: доступен русскоязычным и казахскоязычным студентам области.

## План пилотного внедрения в КПТК за 1 день (п. 8.4 и п. 7.5)

| Время | Шаг | Результат |
|---|---|---|
| 09:00 | Согласование с заместителем директора по воспитательной работе | Утверждён запуск |
| 10:00 | Правка `lib/config.js`: данные колледжа, контакты | Сайт настроен |
| 11:00 | Деплой на Vercel, короткая ссылка | Сайт доступен |
| 12:00 | QR-плакаты: холл, столовая, общежитие | Студенты видят сайт |
| 14:00 | Кураторский час, 15 минут: квиз на телефонах | Первые группы прошли квиз |
| 16:00 | Итоги: отзывы от кураторов голосом или анонимным опросом | Список доработок |

**Измерение результата без сбора данных:** сайт не ведёт аналитику, поэтому охват фиксируют кураторы (сколько групп прошло квиз) и анонимный опрос в конце кураторского часа.

**Масштабируемость (п. 7.5):** один файл настроек, бесплатный хостинг, никаких серверных затрат. Другой колледж области делает копию примерно за час. Следующие этапы: перевод на английский, режим «презентация для куратора», офлайн-режим (PWA).

## Ограничения и честные оговорки

- Правовые формулировки справочные. Перед запуском их стоит сверить с юристом колледжа и актуальной редакцией законов.
- Названия адресатов и телефон 1424 нужно проверить на момент публикации.
- Казахский текст рекомендуется показать преподавателю казахского языка.
- Анонимность зависит и от того, как человек отправит текст. Сайт сам ничего не отправляет.
